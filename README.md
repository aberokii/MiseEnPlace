# BizOnPlus

Hackathon project by team **BizOnPlus**.

## Getting started

```bash
git clone https://github.com/aberokii/BizOnPlus.git
cd BizOnPlus
```

## Team workflow

- `main` is the shared branch. Keep it working.
- Create a branch per feature (`git checkout -b feature/my-thing`), push it, and open a pull request.
- Pull `main` often to avoid merge conflicts.

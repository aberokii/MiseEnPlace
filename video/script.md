## Recording checklist (at feature freeze)

**Screen recordings** (QuickTime, full screen, 1920×1080 or larger, no cursor hunting, one clean take each):
1. `rec-search.mov`: home → type "Le Vent" → pick the result. Stop after the audit page loads.
2. `rec-confirm-audit.mov`: confirm card → "Yes, start the audit" → full loader sequence → results appear. Use demo data (`?cached=1`) so it is repeatable.
3. `rec-results.mov`: scroll the results slowly. Pause 3 s on one Must-have card.
4. Optional if wired: `rec-build.mov`: click "Build it" on the website card and on review replies. If this exists, it replaces the `website` and `replies` clips.

**Café footage** (phone, landscape, 4K if possible, steady): exterior with the sign, a slow push toward the door, one shot of the counter or a coffee. 10–15 s each. Vertical footage still works but gets a blurred side fill.

**Narration**: quiet corner, phone voice memo, 20 cm from the mouth. One file per beat, named `vo-01.m4a` … `vo-12.m4a`. Read each line twice; the better take gets picked. Drop everything into `video/footage/`.
